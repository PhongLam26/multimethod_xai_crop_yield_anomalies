# Reviewer Materials

These files index the reproducibility evidence. They do not alter the locked
selection protocol or convert any sensitivity result into a primary claim.

- `QUICK_REPRODUCTION.md`: fastest verification commands.
- `CLAIM_EVIDENCE_MAP.md`: paper-to-artifact mapping.
- `EXPECTED_RESULTS.md`: numerical expectations and tolerances.
- `ARTIFACT_INDEX.md`: evidence layout.
- `KNOWN_LIMITATIONS.md`: interpretation boundaries.
