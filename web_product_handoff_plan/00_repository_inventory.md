## Important Reusable Components

- `paired_error_pass(ci95_high)` in `src/crop_yield_xai/audit_rules.py`: reusable rule concept for upper-CI-below-zero decisions.
- `top_k_recovery`, `rank_null_audit`, and `topk_null_audit`: reusable event-recovery concepts after direction, block unit, and null settings are made configurable.
- `configs/fidelity_gate.yaml`: authoritative protocol language for Module A/B/E and bootstrap settings.
- `artifacts/gates/*.json` and `artifacts/audit_records/*.csv`: strong examples for immutable run result shapes.
- `tests/test_gate_logic.py`, `tests/test_topk_gate_rule.py`, and `tests/test_synthetic_benchmark_contract.py`: acceptance-test seeds.

## Important Nonreusable Or Hard-Coded Areas

- `src/crop_yield_xai/core.py` hard-codes crop names, weather feature groups, target names, and event thresholds.
- `scripts/run_audit.py` is CLI/file-path coupled and mixes locked prediction audit with artifact writing.
- `scripts/run_eia_external_domain.py` fetches from an external API and uses one specific PJM design.
- XAI pipeline code trains models and computes explanations; V1 workbench should audit uploaded locked predictions only.
- Paper build and PDF crosscheck scripts are not web runtime components.
